# Scalar3D examples

这组 Example 整理 2026-10-08 在四张 NVIDIA A30 上完成的三维标量声波 CUDA 实验。三个算例均包含采集系统、真实和初始模型、反演结果、收敛曲线、中间梯度、炮集与数值检查。这里的切片来自三维体，不是二维传播实验。

- [六面包围异常体](enclosed.md)：照明充分的主功能示例，100 轮后清楚恢复异常体
- [地表采集异常体](surface.md)：数值检查通过，但内部速度恢复不足，保留这一限制
- [起伏薄层模型](layered.md)：Gaussian 平滑初值的轻量辅助示例，100 轮后 RMSE 约降低 20%
- [下载与复现](reproduce.md)：完整报告、已执行 Notebook、脚本和数据的组织方式

## 结果一览

| 算例 | 网格 X × Y × Z | 轮数 | 训练时间 | 全模型 RMSE（m/s） | 固定模型 loss 降幅 |
|---|---|---:|---:|---|---:|
| 六面包围异常体 | 50 × 50 × 30 | 100 | 94.13 s | 39.486 → 4.413 | 99.9791% |
| 地表采集异常体 | 80 × 80 × 50 | 200 | 707.66 s | 25.305 → 23.276 | 96.4050% |
| 起伏薄层模型 | 50 × 50 × 10 | 100 | 77.10 s | 84.704 → 67.714 | 99.8340% |

loss 的降低只说明当前观测目标更匹配。地表算例中心真值为 2300 m/s，最终却为 1948.37 m/s；异常体内 RMSE 仍为 207.96 m/s。因此不能用 96.4050% 的 loss 降幅宣称该模型完整恢复。

## 通用实验配置

运行环境为 4 × NVIDIA A30、PyTorch 2.5.1、CUDA 11.8，GPU 顺序为 `[2, 0, 1, 3]`。实验使用报告所记录的已编译 V11 Scalar3D radius-M 源码；实验期间没有修改传播源码或 CUDA。网页整理不重新运行 GPU，也不把历史源码实验改称为 PyPI wheel 的现场测试。

- 网格间距 10 m，时间步长 0.001 s，完整 25 Hz Ricker 子波
- FWI 使用 4 阶空间差分、PML 宽度 12、buffer 5、`memory='boundary'`、`step_ratio=1`
- Adam 学习率 10.0，每张卡每个 batch 一炮；随机炮序采用固定种子
- 观测与反演采用同一网格、同一算子、无噪声合成数据
- 源码运行模型采用 `(X, Y, Z)`，结果文件保存为 `(Z, Y, X)`；进入传播前必须显式转置，不能仅修改 reshape
- 全部六面使用 PML。顶部传感器处于物理模型内部，未设置压力释放自由表面

异常体初值为均匀 2000 m/s，仅固定外侧三个网格面厚的已知背景；内部体素独立优化，没有球心、形状约束、梯度平滑或结果平滑。薄层初值来自真值的 Gaussian 平滑并固定顶部两个深度网格面（z=0、1）。真值用于合成观测、误差评估与展示；薄层初值这一真值依赖另行明确披露。

当前公开函数的精确参数、轴顺序与返回约定见 {ref}`Usage <scalar>`。实验脚本的特定 XYZ/ZYX 约定不应被推广为所有用户模型唯一允许的地理轴命名。

## 目标、梯度与统计口径

优化目标为归一化均方误差，分母在训练中固定：

```{math}
J(v) = \frac{\operatorname{mean}\left[(F(v)-d_{\mathrm{obs}})^2\right]}{\operatorname{mean}\left[d_{\mathrm{obs}}^2\right]}.
```

训练 pass 平均来自逐 batch 更新的模型。另每十轮对一个固定模型评估全部炮，两种指标分别保存和绘制。RMSE 根据合成真值计算，不参与优化。最终不足的恢复结果也完整保留。

中间梯度在保存模型上重新固定参数并累加全部炮，得到 `dJ/dVp`。原始梯度与已知区域 mask 后的梯度分别保存，没有预条件化。重算 loss 与原固定模型评估对应。每个算例同时展示两套梯度图：

1. 每个 checkpoint 分别除以其全体积 `max|g|`，只比较形态，标题保留原幅值
2. 所有 checkpoint 使用共同原始色标，比较绝对幅值

训练耗时包含每十轮全炮固定模型评估与保存，不含准备、数值检查、观测生成、后补梯度和绘图。服务器同时有其他负载，这些数字不构成独占机器的性能基准。

| 算例 | GPU 2 / 0 / 1 / 3 的峰值 allocated MiB |
|---|---|
| 六面包围 | 113.9 / 101.1 / 101.1 / 101.1 |
| 地表采集 | 296.5 / 257.3 / 257.3 / 257.3 |
| 薄层 | 67.6 / 61.8 / 61.8 / 61.8 |

这些显存数值仅统计训练阶段 PyTorch allocated 峰值，排除 CUDA context、其他使用者和训练前的 full 检查。没有为消耗特定显存额度而填充无用张量。

## 验证范围与限制

三组算例均记录了以下检查：

- **full / boundary**：完全相同采样和采集，逐一覆盖 2、4、6、8 阶，比较记录与模型梯度。记录相对 L2 阈值为 `1e-6`，梯度阈值为 `1e-3`；实测梯度误差约为 `4.35e-7` 至 `7.27e-7`，记录误差为 0
- **内部方向导数**：4 阶，以 `[J(v+εh)−J(v−εh)]/(2ε)` 对照 `∇J·h`，`ε=1 m/s`，相对误差阈值 `5e-3`；三组实测误差为 `1.474e-5`、`7.055e-5`、`9.925e-5`
- **单卡 / 四卡**：对照同样四炮；记录相对误差阈值 `1e-6`，梯度阈值 `1e-4`。记录误差为 0，梯度误差约 `4.54e-8` 至 `1.24e-7`

传播使用 float32，相对范数计算使用 float64。有限差分方向限定在物理模型内部，避免混入继承的模型复制填充与裁剪梯度约定。因此验证的是这些测试配置下的内部离散导数；没有验证未知边缘参数的填充导数，也不是对全部方向、全部模型或全部配置的证明。

本组没有检验真实数据、自由表面、双精度、全部 CFL、任意边界位置或噪声鲁棒性。没有独立证明地表算例中炮密度、频带、初值和学习率分别带来多少影响。编译成功、图像好看、loss 下降均不能单独证明梯度正确；数值检查通过也不保证模型可完整恢复。
