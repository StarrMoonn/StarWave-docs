# What is StarWave?

StarWave is a differentiable wave-propagation toolkit for PyTorch that connects subsurface models, simulated observations, and model updates. CUDA handles propagation, while PyTorch autograd carries loss gradients back to the model, bringing forward modeling and inversion into a familiar tensor-and-optimizer workflow.

Read or download the [original 30-slide presentation](presentation.md) for an overview of FWI, automatic differentiation, and the StarWave workflow.

## What it provides

- **Wave simulation**: 2D scalar acoustics, 2D VRZ, and 2D/3D acoustic VTI, each with its own medium parameters, source conventions, and recorded quantities.
- **Gradients and FWI**: connect simulated records to a PyTorch loss, compute first-order model gradients, and update models in your own optimization loop.
- **Neural model representations**: pass a complete model generated by a user-defined network to the propagator and explore implicit neural representations (INRs) with wave physics.

The current propagators use CUDA float32 models, with fixed source waveforms and acquisition locations. See [Usage](usage.md) for types, shapes, units, and constraints.

## Origins and development

StarWave adapts CUDA propagation kernels from MIT-licensed [SWEEP](https://github.com/DeepWave-KAUST/sweep) and retains upstream attribution and license notices. Its development builds on that foundation with a unified PyTorch interface, model-gradient handling, input checks, and inversion workflows.

StarWave's call style takes cues from [Deepwave](https://github.com/ar4/deepwave), and selected time-resampling utilities are adapted from Deepwave. Its validation work also uses Deepwave reference code, with applicable MIT notices retained. [Deepwave's Usage documentation](https://ausargeo.com/deepwave/usage) inspired this manual's organization. StarWave's supported equations, parameter conventions, and return values are defined in this manual.
